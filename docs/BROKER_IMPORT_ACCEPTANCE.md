## Known boundaries and manual acceptance

1. After active research finishes, restart Ledger normally to load new backend
   code and schema. No running user service was restarted during development.
2. Configure a read-only demo provider using `.env.example`; test connection,
   select the verified account, then Sync now. Compare broker facts and currencies.
3. Sync again: no duplicate trades. Add review notes/screenshots and resync: IDs,
   notes and attachments must remain. Switch accounts/environment: rows stay separate.
4. MT5 requires optional package + local terminal. Quantities are lots; reversals
   and separate position cash adjustments are rejected, not guessed. MT4 is absent.
5. TradeLocker history is order aggregates with last-modified timestamps; missing
   realized P&L/costs remain unavailable. Full bounded reads support incremental
   reconciliation, not an undocumented modification-time network cursor.
6. Disconnect pauses a profile without deleting its data or erasing environment
   credentials. Removing credentials is a separate local configuration operation.
7. Live broker acceptance remains **not performed**. Automated fixtures demonstrate
   reconciliation contracts; they do not establish an account's API entitlement,
   broker history retention or local terminal compatibility.
8. Existing user strategy edits and drafts remain outside the commit. A pre-existing
   trailing space in turtle_donchian_research_v1.py causes whole-working-tree
   `git diff --check` to fail; scoped/staged checks must pass without editing it.
